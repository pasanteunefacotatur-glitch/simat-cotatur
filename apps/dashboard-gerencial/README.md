# Panel Estadístico y Gerencial (`apps/dashboard-gerencial`)

Directorio base para el módulo administrativo y analítico de COTATUR (Fase 3):
- Visualización de KPIs compuestos (Total de visitantes, tamaño medio de grupo, estadía promedio, calificación por servicio).
- Filtros por temporada turística, punto de control, municipio de destino y procedencia.
- Generador de códigos QR de baja densidad y enlaces parametrizados (`?p=CODIGO`).
- Exportación de reportes en formatos `.xlsx` y `.csv` sanitizados.
